## 📌 About The Project

**Webathon 4** is a modern web project developed using **Next.js and TypeScript**.

The project focuses on creating a responsive, user-friendly interface with reusable components and a clean project structure.

* 🔤 TypeScript support
* 📐 Responsive layouts
* 🚀 Optimized production build

## ⚙️ Getting Started

First, install the required dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open http://localhost:3000 with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

## 🚀 Available Commands

### Development

```bash
npm run dev
```

Runs the development server locally.

### Production Build

```bash
npm run build
```

Creates an optimized production build.

### Start Production Server

```bash
npm start
```

Runs the production server.

### Lint

```bash
npm run lint
```

Checks the project for linting and code-quality issues.
